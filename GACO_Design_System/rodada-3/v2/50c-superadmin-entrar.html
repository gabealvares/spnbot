Sobre esta tela: Entrar no cliente com motivo e prazo

O que esta tela resolve

A equipe do GACO só entra num cliente com motivo, prazo e segundo fator, e o cliente fica sabendo. Dentro, uma faixa laranja fica sempre visível com motivo, tempo que falta, "Estender" e "Sair do cliente".

Fluxo

  1. "Entrar no cliente" (painel, lista ou detalhe) abre este modal.
  2. Motivo, número do chamado, o que vai fazer, prazo e permissão.
  3. Código do 2º fator; "Entrar por 60 min" abre o sistema do cliente com a faixa (50c2).
  4. Cancelar, X ou Esc fecham sem registrar nada.

Resolvemos fazer assim porque

o Zendesk e o Intercom pedem motivo para "assumir a conta", o Google Workspace avisa o cliente pelo Access Transparency e o AWS exige MFA para elevar o acesso por tempo limitado. Enviamos para aprovação.

Acessibilidade desta tela

Ordem de foco

  1. Motivo, chamado, descrição
  2. Prazo e permissão (grupos de rádio)
  3. Código do 2º fator
  4. Cancelar, Entrar

O que é anunciado

  • O botão diz o prazo: "Entrar por 60 min"
  • Dentro do cliente, a faixa é role=status e anuncia motivo e tempo

Nome do que é só ícone

  • X: "Fechar"
